Projeto desenvolvido em Java utilizando o padrão de projeto **Adapter** aplicado em um sistema de hamburgueria.

O objetivo é demonstrar como integrar sistemas com interfaces incompatíveis sem alterar suas implementações originais.

O padrão **Adapter** permite que classes com interfaces diferentes trabalhem juntas.

Ele atua como um adaptador entre dois sistemas incompatíveis, convertendo chamadas de um formato para outro.
